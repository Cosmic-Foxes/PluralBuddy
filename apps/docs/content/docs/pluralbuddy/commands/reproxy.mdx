---
title: pb;reproxy
description: Reproxy a message with a different alter.
---

This command deletes the previously sent message.

### Usage

*All arguments in `<value>` format are required. All arguments in `[value]` are optional.*

```
pb;reproxy <alter name>
```

<Callout type="warning"> Only messages sent by your system can be reproxied. </Callout>

You can reply to a message to specifically target the replied message to be reproxied.
