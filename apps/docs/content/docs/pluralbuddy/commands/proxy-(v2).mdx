---
title: pb;proxy (v2)
description: Enable or disable proxying for your system.
---

This command allows you to enable or disable proxying for your system.
## Usage

_All arguments in the `<value>` format are required._

```
pb;proxy <enable/disable>
```

<Callout title="Status Only Applies to Server" type="warning">
    This command only applies the proxy status to the **current server**.
</Callout>
